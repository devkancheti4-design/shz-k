How it works

Each kind of content, its cheapest exact method

Every rule is verified while compressing, so decompression is always byte-identical. Every integer law in the codec is machine-authored by integer program synthesis and proven on every input of its domain.

The float law

A number whose text is the shortest decimal of a float32 becomes its 4 bytes; the digits are regenerated exactly.

The bytes law

A token's list of UTF-8 byte values is rebuilt from the token text instead of stored.

JSON as columns

Each float belongs to a field, by key or by list position, so similar values sit together.

Byte planes

The sign-and-exponent byte of a float is coded; random mantissa bytes are stored as they are.

Text by block sorting

What remains is prose and keys; block sorting (bsc) codes it fast.

Lines and numbers

For logs and tables: the line above token by token, counters carried forward, field recall.

Everyone can check

Reproduce every number

Compressed sizes do not depend on the machine: shz-k is integer code and bsc is pinned to one commit. The kit fetches the public data, checks every hash, proves every law, reruns the sealed tests, and compares your sizes to the reference to the byte.

git clone https://github.com/devkancheti4-design/shz-k && cd shz-k
./build.sh                  # bsc (pinned), the codecs; proves every law on its whole domain
./fetch_data.sh ai          # WildChat-1M shard 0, 230.8 MB; hashes checked
./run.sh ai                 # chat transcripts: exactness, then every codec
./run.sh aiapi              # embeddings and log-probabilities (data included)
python3 report.py           # tables and verdicts with your prices.json
python3 verify.py           # REPRODUCED if every shz-k and bsc size is identical

Where it is not the answer

  • Decompression runs at 20–51 MB/s; LZ decoders run at hundreds to thousands. For data read many times a month, set reads per month above.
  • On human prose and on binaries, block-sorting and LZ compressors are cheaper. shz-k wins on machine-written data.
  • General benchmarks, for reference: enwik9 rank 50 of 234 (Large Text Compression Benchmark), Silesia rank 73 of 324.
  • Each AI result rests on one dataset; the embeddings and log-probabilities were generated by small open models in real API formats.
